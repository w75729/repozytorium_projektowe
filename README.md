# Antykwariat Akgun

Projekt semestralny - prosta aplikacja internetowa do zarzadzania lista ksiazek w antykwariacie.

Autor: Furkan Akgun  
Numer indeksu: 75729

## Technologie

- HTML
- CSS
- JavaScript
- Firebase Realtime Database
- GitHub Pages

## Planowane funkcje

- dodawanie ksiazki,
- zapis ksiazek do Firebase,
- pobieranie ksiazek z Firebase,
- wyswietlanie listy ksiazek,
- wyswietlanie szczegolow ksiazki,
- usuwanie ksiazki,
- wyszukiwanie po tytule lub autorze,
- prosta walidacja formularza.
